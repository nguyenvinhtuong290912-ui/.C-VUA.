# ROYAL CLASH — bản cập nhật

## Tính năng
- Bấm quân đang tới lượt để xem nước đi hợp lệ.
- Ô trống có thể đi được đánh dấu bằng chấm.
- Ô có quân đối phương có thể ăn được đánh dấu bằng dấu ✕ ngay trên ô đó.
- Tuân thủ luật hợp lệ, vật cản, vua không được đi vào chiếu.
- Chơi với AI mức Dễ / Trung bình / Khó hoặc chơi 2 người.
- Nhạc nền tạo trong trình duyệt, bật/tắt bằng nút nhạc.
- Đi lại một nước, ván mới, tọa độ ô trong tooltip.

## Chạy trên Streamlit
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Đưa lên GitHub / Streamlit Cloud
Tải `app.py`, `requirements.txt` lên repository. Trên Streamlit Cloud, chọn nhánh `main` và Main file path `app.py`.

Ghi chú: Đây là bản thay thế độc lập vì file nguồn ROYAL CLASH hiện tại chưa có trong tệp được cung cấp ở cuộc trò chuyện. Hãy sao lưu repository cũ trước khi thay.
